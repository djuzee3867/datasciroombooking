# DataSci Room Booking — UI Demo

ระบบจองห้องอาคาร SCB4 คณะวิทยาศาสตร์ข้อมูล — **รุ่น UI ล้วน (ยังไม่มีฐานข้อมูล/ระบบล็อกอินจริง)**

โปรเจกต์นี้มีเฉพาะส่วน **หน้าจอ (UI)** ที่ทำงานได้จริงบน **ข้อมูลตัวอย่าง (mock data) ในหน่วยความจำ**
เหมาะสำหรับให้ทีมนำไปต่อยอด — เชื่อมฐานข้อมูลจริง / ระบบล็อกอิน / แบ่งบทบาท ในภายหลัง

> ⚠️ ข้อมูลอยู่ในหน่วยความจำของเบราว์เซอร์เท่านั้น — จอง/อนุมัติ/แก้ไขได้ระหว่างใช้งาน
> แต่เมื่อ **รีเฟรชหน้า ข้อมูลจะกลับไปเป็นชุดตัวอย่างเดิม**

## ความต้องการของเครื่อง

- [Node.js](https://nodejs.org/) เวอร์ชัน 20 ขึ้นไป (มาพร้อม `npm`)
- [Git](https://git-scm.com/)

## เริ่มต้นใช้งาน (สำหรับสมาชิกในทีม)

```bash
# 1. โคลนโปรเจกต์ (repo เป็นแบบส่วนตัว ต้องได้รับสิทธิ์เข้าถึงก่อน)
git clone https://github.com/djuzee3867/datasciroombooking.git
cd datasciroombooking

# 2. ติดตั้ง dependencies
npm install

# 3. รันเซิร์ฟเวอร์สำหรับพัฒนา
npm run dev
```

เปิดเบราว์เซอร์ที่ http://localhost:3000

คำสั่งอื่น ๆ:

```bash
npm run build   # build สำหรับ production
npm run start   # รันเวอร์ชัน production ที่ build แล้ว
npm run lint    # ตรวจโค้ดด้วย ESLint
```

## การเข้าใช้งาน (โหมดปัจจุบัน)

รุ่นนี้ยังไม่แบ่งบทบาท จึง **ล็อกอินอัตโนมัติเป็นผู้ดูแลระบบ (SUPER_ADMIN)** ให้เข้าได้ทุกหน้าทันที
โดยไม่ต้องล็อกอิน — หน้า `/login` และ `/signup` ยังใช้งานได้เป็นเดโม (รหัส OTP ทดสอบคือ `000000`)

บทบาทที่มีในระบบตอนนี้: **ผู้ใช้ทั่วไป (USER) · แอดมิน (ADMIN) · ผู้ดูแลระบบ (SUPER_ADMIN)**
สลับเป็นผู้ใช้อื่นได้โดยล็อกอินด้วยอีเมลของบัญชีตัวอย่างในหน้า `/login`

ห้องในระบบตอนนี้มี 3 ห้อง:

| รหัส | ชื่อ | จองได้ |
| --- | --- | --- |
| SCB4101 | ห้องเมเจอร์ Data Science 1 | ✓ |
| SCB4102 | ห้องเมเจอร์ Data Science 2 | ✓ |
| SCB4203 | ห้อง DSRC | ✓ |

## โครงสร้างโปรเจกต์

```
src/
├─ app/            หน้าเว็บทั้งหมด (Next.js App Router)
│  ├─ page.tsx        หน้าแรก — ค้นหา/ดูตารางห้อง
│  ├─ book/           หน้าจองห้อง
│  ├─ my-bookings/    การจองของฉัน
│  ├─ admin/          หน้าแอดมิน (อนุมัติ · จัดการห้อง · สิทธิ์ · ตั้งค่า · audit)
│  ├─ rooms/[code]/   รายละเอียดห้อง
│  ├─ display/[code]/ จอแสดงหน้าห้อง
│  ├─ stats/ guide/ privacy/ login/ signup/
├─ components/     ส่วนประกอบ UI ที่ใช้ร่วมกัน
└─ lib/
   ├─ data/seed.ts   ข้อมูลตัวอย่าง (mock)
   ├─ db/            ชั้นข้อมูล in-memory (แทน backend จริง)
   │  ├─ mockdb.ts        ก้อน Db จำลอง · เซสชันจำลอง · ที่เก็บไฟล์แนบ
   │  ├─ actions.ts       จอง/อนุมัติ/ยกเลิก/บล็อกเวลา
   │  ├─ admin-actions.ts จัดการห้อง/สิทธิ์/ภาคเรียน/audit/ส่งออก
   │  └─ auth-actions.ts  auth จำลอง
   ├─ store.tsx      React store — โหลด seed แล้วกระจายให้ทุกหน้า
   ├─ repo.ts        ฟังก์ชันอ่านข้อมูล (บริสุทธิ์)
   ├─ conflicts.ts   ตรรกะกันจองชน + ตรวจฟอร์ม
   ├─ policy.ts      นโยบายระบบ (เวลาให้บริการ, กติกาการจอง ฯลฯ)
   ├─ time.ts        เครื่องมือจัดการเวลา (ยึด Asia/Bangkok)
   └─ types.ts       รูปทรงข้อมูลกลาง
```

## จะต่อ backend จริงทำอย่างไร

ชั้นข้อมูลทั้งหมดถูกแยกไว้ใน `src/lib/db/*` โดย **คงลายเซ็นฟังก์ชันเดิม** ไว้
เมื่อจะต่อฐานข้อมูล/ระบบล็อกอินจริง ให้แก้เฉพาะไฟล์เหล่านี้ (เปลี่ยนจากการแก้ก้อน Db
ในหน่วยความจำ เป็นการยิง query จริง) โดย **ไม่ต้องแก้หน้าจอ** — UI ทุกหน้าเรียกผ่าน
`useStore()` เท่านั้น
